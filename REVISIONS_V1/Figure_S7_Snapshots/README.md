# Structure Snapshots

**Data for:** Figure S7 — Snapshots

This is an image-only folder (no scripts or raw data): it collects the rendered structure snapshots used in the Supporting Information.

| File | Description |
|------|-------------|
| `Nitrobenzene_Direction_A_Snapshots.png` | Snapshot panel of the nitrobenzene AIMD trajectory propagated with the cavity field along direction A (θ = 70°, φ = 31°). Source trajectory: `Figure_05_Molecular_Dynamics_on_Relaxed_Surface/nitrobenzene_direction_A_wb97x_d_4000_ts.xyz` |
| `Wheland_Snapshots.png` | Snapshot panel of the bromo-nitrobenzene Wheland intermediates (ortho / meta / para). Source geometries: the pristine and relaxed structures of the Figure_02 campaign (`Figure_02_Relaxed_Theta_Phi_Scan/QED_DFT_Theta_Phi_Relax_Campaign/`) |

Related data:

- Figure_02 — relaxed (θ, φ) scan and optimized Wheland-intermediate geometries
- Figure_05 / Figure_06 — the direction-A/D trajectories and their analyses
- Figure_01 — common coordinate-system scheme for the intermediates
